# Política de segurança

## Versões suportadas

Enquanto o projeto estiver no Hackathon, a versão suportada é a branch `main` e as releases mais recentes.

## Reportar uma vulnerabilidade

Não publique detalhes de uma vulnerabilidade crítica em issue pública. Envie o relatório por um Security Advisory privado do GitHub, quando habilitado, ou solicite aos mantenedores um canal privado pelo repositório. Inclua impacto, passos para reproduzir e uma sugestão de correção, sem anexar segredos reais.

Após a correção, credenciais potencialmente expostas devem ser revogadas e substituídas.
